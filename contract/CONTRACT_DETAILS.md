# BBoard Contract — Details & Build

This document describes where the bulletin-board (BBoard) contract artifacts live, how to build them, and where supporting keys/zkir live.

## Locations

- Contract source (compact DSL): `contract/src/bboard.compact`
- Generated JS contract (checked-in managed output): `contract/src/managed/bboard/contract/index.js`
- Managed keys and ZKIR blobs: `contract/src/managed/bboard/keys/` and `contract/src/managed/bboard/zkir/`

## Build / Compile

From the repository root (WSL/Ubuntu):

```bash
cd /home/rudra/leveling/contract
npm run compact      # runs compact compiler, generates managed sources
npm run build        # transpile TypeScript and copy managed artifacts to dist/
npm test             # run contract unit tests (vitest)
```

Notes:
- `npm run compact` uses the `compact` CLI to compile `src/bboard.compact` into `src/managed/bboard/`.
- The application currently imports compiled contract code from the managed path under `contract/src/managed/...` so regenerating must preserve that structure.

## Artifacts used by the app

- The UI and API expect the compiled contract to be available at `contract/src/managed/bboard/contract/index.js` (or under `dist/managed` for packaged builds).
- Keys and ZKIR files are read/copied by `bboard-ui`'s `predev` script into `bboard-ui/public/` for the dev server.

## Keys & ZKIR

- Developer keys and `*.zkir` blobs are stored in `contract/src/managed/bboard/keys/` and `contract/src/managed/bboard/zkir/`.
- If you regenerate the contract, ensure the relevant keys and zkir blobs are also available for `bboard-ui` to copy during `npm run dev`.

## Troubleshooting

- If Vite reports sourcemap or missing-source errors for the generated contract, either regenerate the managed sources without sourceMap comments or ensure source files are available for the map.
- If transactions fail to show balances or state updates, ensure the contract was compiled with the expected `compact`/runtime version and that `contract/src/managed` artifacts are in sync with `contract/src/bboard.compact`.
